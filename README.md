
# Yandex Music Visualizer for Hexlet

Яндекс Музыка в визуализации Хекслета

## О проекте

Yandex Music Visualizer - это веб-приложение для прослушивание музыки в визуализации Хекслета. Пет-проект будет состоять из экосистемы хекслета и подстроен под ui/ux hexlet

Приложение будет делать следующее: Статистика, что было прослушено. Доступ к экосистеме хекслета. Музыка для технарей). Авторизация/Регистрации и выбор вкуса.
Песни будут статически, то есть всего будет 15 песен на разные вкусы

## Стек

- React + TypeScript;
- React Router;
- Zustand;
- Zod;
- CSS-переменные и собственный UI-кит в стиле Хекслета.

## Архитектура

Структура проекта (FSD). Будет архитектура Feature-Sliced Design, нужно для того, чтобы была четкая иерархия, на подобие чистой архитектуры. В будущем будет удобно расширять функционал проекта


- `app` — инициализация, провайдеры, роутер, глобальные стили
- `pages` — страницы и маршруты
- `widgets` — крупные блоки шапка, плеер, список треков
- `features` — пользовательские сценарии: вход, выбор вкуса, управление плеером
- `entities` — бизнес-сущности: пользователь, трек, вкус, сессия
- `shared` — UI-кит, утилиты, конфиг, работа с localStorage

Импорты идут только вниз по цепочке. `shared` не знает о домене, `entities` не знают о `features`

## Структура

```text
src/
├── app/       # провайдеры, роутер, стили
├── pages/     # страницы
├── widgets/   # шапка, плеер, списки
├── features/  # вход, выбор вкуса, плеер
├── entities/  # пользователь, трек, вкус, сессия
└── shared/    # UI-кит, утилиты, конфиг
```
